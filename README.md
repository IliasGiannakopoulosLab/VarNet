# MRI Reconstruction with VarNet, Learnable Sampling, and Pixelwise Uncertainty

This repository provides a PyTorch Lightning implementation for **2D accelerated MRI reconstruction** using variational networks. It supports fixed and jointly optimized 1D Cartesian undersampling patterns, together with a separate pixelwise uncertainty estimation pipeline based on quantile regression and conformal calibration.

The repository includes:

- End-to-end VarNet (`e2e_varnet`)
- Feature-image VarNet (`fi_varnet`)
- Fixed 1D Cartesian undersampling masks
- Learnable 1D Cartesian undersampling masks optimized jointly with reconstruction
- Pixelwise uncertainty estimation for fixed-mask and learned-mask reconstructions

Both E2E VarNet and FI VarNet can be trained with either fixed or learnable masks. The uncertainty pipeline is compatible with all four combinations.
---

## Supported workflows

| Reconstruction model | Fixed mask | Learnable mask | Pixelwise uncertainty |
|---|---:|---:|---:|
| E2E VarNet | Yes | Yes | Yes |
| FI VarNet | Yes | Yes | Yes |

The reconstruction loss is SSIM loss for all reconstruction configurations.

## Reconstruction models

### E2E VarNet

The end-to-end variational network follows the standard multicoil reconstruction pipeline:

```text
undersampled k-space
    -> sensitivity estimation
    -> cascaded image-domain regularization and data consistency
    -> reconstructed magnitude image
```

Select it with:

```bash
MODEL_NAME=e2e_varnet
```

### FI VarNet

The feature-image variational network follows the same general unrolled reconstruction structure but performs part of the learned regularization in a feature-image domain.

Select it with:

```bash
MODEL_NAME=fi_varnet
```

## Undersampling masks

### Fixed masks

Fixed-mask experiments use predefined 1D Cartesian phase-encoding patterns. The currently supported mask types are:

```text
equispaced
equispaced_fraction
```

Use:

```bash
MASK_MODE=fixed
FIXED_MASK_TYPE=equispaced_fraction
```

The fixed mask is generated by the data transform before the reconstruction model is called.

### Learnable 1D Cartesian mask

The learnable-mask mode jointly optimizes the reconstruction network and a probability assigned to each phase-encoding line outside the fully sampled center.

Use:

```bash
MASK_MODE=learnable
NUM_LOGITS=320
```

The learnable mask has the following behavior:

- A contiguous central region remains fully sampled.
- The outer phase-encoding probabilities are learned jointly with the VarNet weights.
- The sampling probabilities are normalized to the budget defined by `ACCELERATION` and `CENTER_FRACTION`.
- Training uses Bernoulli sampling with a straight-through gradient estimator.
- Validation, testing, calibration, and uncertainty inference use a deterministic highest-probability mask with the exact rounded sampling budget.
- The learned parameter vector is defined on a canonical support of length `NUM_LOGITS` and is interpolated when the acquired phase-encoding support has a different width.

The deterministic evaluation mask is important because reconstruction testing and uncertainty inference must use the same learned sampling pattern.

Learnable-mask mode currently requires exactly one acceleration and one center fraction per run. A batch size of one is recommended when acquisition support widths vary between examples.

The reconstruction and mask can use separate learning rates:

```bash
VN_LR=0.0003
VN_LR_BASE=0.0003
VN_LR_MASK=0.0003
```

When `VN_LR_BASE` or `VN_LR_MASK` is left empty, it defaults to `VN_LR`.

## Pixelwise uncertainty estimation

The uncertainty model is trained after the reconstruction model has been trained. The reconstruction network is frozen, and a separate network predicts lower and upper bounds around the VarNet reconstruction. The bounds are trained using pinball loss and calibrated using conformal prediction.

The uncertainty workflow is:

```text
train VarNet and, when selected, the learnable mask
    -> test VarNet and save reconstructions
    -> freeze the complete reconstruction model
    -> train the uncertainty model
    -> calibrate the uncertainty intervals
    -> test the uncertainty model
    -> append uncertainty maps to the reconstruction HDF5 files
```

For learned-mask experiments, the reconstruction checkpoint contains both the VarNet weights and the learned mask parameters. The uncertainty runner loads and freezes the complete model. A fixed-mask checkpoint cannot be used as a learned-mask checkpoint because it does not contain trained mask parameters.

The same values of the following variables must be used for reconstruction and uncertainty:

```bash
MODEL_NAME
MASK_MODE
ACCELERATION
CENTER_FRACTION
NUM_LOGITS
NUM_CASCADES
CHANS
POOLS
SENS_CHANS
SENS_POOLS
```

## Dataset format

The code expects fastMRI-style HDF5 files containing multicoil k-space data and the corresponding RSS reconstruction target.

A typical folder structure is:

```text
/path/to/data/
  knee/
    multicoil_train/
    multicoil_val/
    multicoil_cal/
    multicoil_test/

  brain/
    multicoil_train/
    multicoil_val/
    multicoil_cal/
    multicoil_test/
```

The calibration split is used only by the uncertainty workflow.

## Before running: update `batch_run.sh`

`batch_run.sh` contains paths from the original development environment. Update the following variables before running the repository on another machine or cluster:

```bash
HOME_DIR=/path/to/project_or_data_root
VARNET_DIR=/path/to/this/repository
LOG_PATH=/path/to/output/logs
DATA_DIR=/path/to/data/${ANATOMY}/
VN_TRAIN_PATH=/path/to/data/${ANATOMY}/multicoil_train/
VN_VAL_PATH=/path/to/data/${ANATOMY}/multicoil_val/
VN_CAL_PATH=/path/to/data/${ANATOMY}/multicoil_cal/
VN_TEST_PATH=/path/to/data/${ANATOMY}/multicoil_test/
```

You may also need to edit the SLURM header:

```bash
#SBATCH --partition=radiology
#SBATCH --cpus-per-task=10
#SBATCH --time=3-00:00:00
#SBATCH --mem=300G
#SBATCH --gres=gpu:a100:1
```

Change the partition, GPU type, memory, wall time, and other resource requests to match your system.

## Main `batch_run.sh` variables

### Experiment and sampling controls

```bash
ANATOMY=knee                     # knee or brain
MODEL_NAME=e2e_varnet            # e2e_varnet or fi_varnet
ACCELERATION=4
CENTER_FRACTION=0.08
MASK_MODE=fixed                  # fixed or learnable
FIXED_MASK_TYPE=equispaced_fraction
NUM_LOGITS=320                   # used only for learnable masks
PRECISION=32
BATCH_SIZE=1
NUM_WORKERS=4
```

When `CENTER_FRACTION` is left empty, `batch_run.sh` uses the following defaults:

```text
2x  -> 0.16
4x  -> 0.08
6x  -> 0.06
8x  -> 0.04
10x -> 0.02
```

```bash
NUM_CASCADES=12

```

## Reconstruction examples

Most experiments are launched through `batch_run.sh`.

### Train E2E VarNet with a fixed mask

```bash
sbatch \
  --job-name=E2E_K_4x_fixed_train \
  --export=ALL,ANATOMY=knee,MODEL_NAME=e2e_varnet,MASK_MODE=fixed,FIXED_MASK_TYPE=equispaced_fraction,ACCELERATION=4,RUN_TRAINING=true,RUN_TESTING=false,RUN_EVALUATION=false \
  batch_run.sh
```

### Train E2E VarNet with a learnable mask

```bash
sbatch \
  --job-name=E2E_K_4x_learned_train \
  --export=ALL,ANATOMY=knee,MODEL_NAME=e2e_varnet,MASK_MODE=learnable,NUM_LOGITS=320,ACCELERATION=4,CENTER_FRACTION=0.08,RUN_TRAINING=true,RUN_TESTING=false,RUN_EVALUATION=false \
  batch_run.sh
```

### Train FI VarNet with a learnable mask

```bash
sbatch \
  --job-name=FI_K_4x_learned_train \
  --export=ALL,ANATOMY=knee,MODEL_NAME=fi_varnet,MASK_MODE=learnable,NUM_LOGITS=320,ACCELERATION=4,CENTER_FRACTION=0.08,RUN_TRAINING=true,RUN_TESTING=false,RUN_EVALUATION=false \
  batch_run.sh
```

### Test and evaluate a reconstruction model

Use the same model and mask settings used during training:

```bash
sbatch \
  --job-name=E2E_K_4x_learned_test \
  --export=ALL,ANATOMY=knee,MODEL_NAME=e2e_varnet,MASK_MODE=learnable,NUM_LOGITS=320,ACCELERATION=4,CENTER_FRACTION=0.08,RUN_TRAINING=false,RUN_TESTING=true,RUN_EVALUATION=true \
  batch_run.sh
```

Reconstruction outputs are saved under:

```text
${LOG_PATH}/${MODEL_NAME}/reconstructions_${VN_MODEL}/
```

The model name includes the anatomy, reconstruction model, acceleration, loss, and mask type. Fixed and learned experiments therefore use separate checkpoint and reconstruction directories.

## Uncertainty workflow examples

The following examples use E2E VarNet with a learned mask. The same commands work for FI VarNet by setting `MODEL_NAME=fi_varnet`, and for fixed masks by setting `MASK_MODE=fixed` and `FIXED_MASK_TYPE`.

### Train the uncertainty model

```bash
sbatch \
  --job-name=E2E_K_4x_learned_unc_train \
  --export=ALL,ANATOMY=knee,MODEL_NAME=e2e_varnet,MASK_MODE=learnable,NUM_LOGITS=320,ACCELERATION=4,CENTER_FRACTION=0.08,RUN_TRAINING=false,RUN_TESTING=false,RUN_EVALUATION=false,RUN_UNCERTAINTY_TRAINING=true,RUN_UNCERTAINTY_CALIBRATION=false,RUN_UNCERTAINTY_TESTING=false \
  batch_run.sh
```

### Calibrate the uncertainty intervals

```bash
sbatch \
  --job-name=E2E_K_4x_learned_unc_cal \
  --export=ALL,ANATOMY=knee,MODEL_NAME=e2e_varnet,MASK_MODE=learnable,NUM_LOGITS=320,ACCELERATION=4,CENTER_FRACTION=0.08,RUN_TRAINING=false,RUN_TESTING=false,RUN_EVALUATION=false,RUN_UNCERTAINTY_TRAINING=false,RUN_UNCERTAINTY_CALIBRATION=true,RUN_UNCERTAINTY_TESTING=false \
  batch_run.sh
```

### Test the uncertainty model

Run reconstruction testing first so that the reconstruction HDF5 files exist. Then run:

```bash
sbatch \
  --job-name=E2E_K_4x_learned_unc_test \
  --export=ALL,ANATOMY=knee,MODEL_NAME=e2e_varnet,MASK_MODE=learnable,NUM_LOGITS=320,ACCELERATION=4,CENTER_FRACTION=0.08,RUN_TRAINING=false,RUN_TESTING=false,RUN_EVALUATION=false,RUN_UNCERTAINTY_TRAINING=false,RUN_UNCERTAINTY_CALIBRATION=false,RUN_UNCERTAINTY_TESTING=true \
  batch_run.sh
```

## Saved reconstruction files

Each test HDF5 file contains:

```text
reconstruction
mask_1d
support_width
effective_acceleration
acq_start
acq_end
```

After uncertainty testing, the same file also contains:

```text
uncertainty_map
```

For learned-mask experiments, `mask_1d` is the deterministic learned mask used for inference.

## Recommended first run

A stable first experiment is:

```bash
ANATOMY=knee
MODEL_NAME=e2e_varnet
ACCELERATION=4
CENTER_FRACTION=0.08
MASK_MODE=fixed
FIXED_MASK_TYPE=equispaced_fraction
PRECISION=32
```

Recommended sequence:

1. Train the reconstruction model.
2. Test the reconstruction model.
3. Evaluate reconstruction metrics.
4. Train the uncertainty model.
5. Calibrate the uncertainty intervals.
6. Test uncertainty and append the uncertainty maps.

After confirming the fixed-mask workflow, change `MASK_MODE=learnable` to train the sampling pattern jointly with the reconstruction network.
